Kebijakan Privasi

Terakhir diperbarui: 23 November 2026

Data gaji dan karyawan Anda disimpan di perangkat Anda dan di Google Drive Anda sendiri. Kami tidak punya database pengguna dan tidak menyimpan data usaha Anda di server kami.

Siapa kami

SiGaji adalah aplikasi web untuk mencatat absensi, bonus, kasbon, dan menghitung gaji karyawan. Aplikasi ini dikelola oleh NAMA_PENGELOLA ("kami"). Kontak: EMAIL_KONTAK.

Data yang diproses

  • Informasi akun Google (nama dan alamat email), hanya jika Anda memilih masuk dengan Google. Dipakai untuk menampilkan akun mana yang tersambung.
  • Data usaha yang Anda masukkan: profil usaha, jabatan, data karyawan (termasuk NIK, nomor HP, alamat, dan rekening bank jika Anda mengisinya), absensi, hari libur, bonus, kasbon, dan hasil penggajian.
  • Token akses Google berupa refresh token, untuk mengakses folder aplikasi di Drive Anda atas nama Anda.

Izin Google yang diminta

  • drive.appdata: membaca dan menulis satu file data aplikasi (sigaji-db.json) di folder tersembunyi milik aplikasi di Drive Anda. Izin ini tidak memberi akses ke file lain di Drive Anda.
  • email dan profile: menampilkan nama dan email akun Anda.

Cara kami menggunakan data

Data hanya dipakai untuk menjalankan fitur aplikasi: menyimpan dan menyinkronkan data Anda antar perangkat. Kami tidak menjual data, tidak membagikannya untuk iklan, dan tidak menggunakannya untuk melatih model apa pun.

Penggunaan dan pengalihan informasi yang diterima dari Google API oleh SiGaji mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas (Limited Use).

Di mana data disimpan

  • Di perangkat Anda: browser menyimpan salinan data (localStorage) agar aplikasi tetap bisa dipakai tanpa internet.
  • Di Google Drive Anda: file data aplikasi, jika Anda masuk dengan Google.
  • Di server kami: tidak ada data usaha yang disimpan. Saat sinkronisasi, data melewati server Worker kami hanya untuk diteruskan ke Google Drive, lalu tidak disimpan. Refresh token disimpan terenkripsi di cookie browser Anda, bukan di database kami.

Cookie dan penyimpanan lokal

  • sg_s: sesi masuk terenkripsi, HttpOnly, berlaku sampai 180 hari atau sampai Anda keluar.
  • sg_o: penanda keamanan saat proses masuk, berlaku 10 menit.
  • localStorage dan cache aplikasi: data dan berkas aplikasi untuk penggunaan offline.

Kami tidak memakai cookie iklan atau pelacak analitik.

Pihak ketiga

  • Google: autentikasi dan penyimpanan Drive.
  • Cloudflare: hosting aplikasi dan server Worker. Cloudflare dapat mencatat data teknis seperti alamat IP dan waktu akses sesuai kebijakannya sendiri.
  • Penyedia pustaka dan font (Tailwind CSS, Font Awesome, jsPDF, Google Fonts): browser Anda memuat berkas dari server mereka, sehingga mereka dapat menerima alamat IP dan jenis browser Anda. Data usaha Anda tidak dikirim ke mereka.

Data karyawan Anda

Jika Anda memasukkan data pribadi karyawan, Anda bertanggung jawab memastikan pengumpulan dan penggunaannya sah, termasuk memberi tahu dan, bila perlu, meminta persetujuan karyawan sesuai peraturan yang berlaku di Indonesia, seperti UU Pelindungan Data Pribadi.

Kontrol dan penghapusan data

  • Keluar: tombol Keluar di halaman Data menghapus sesi dari browser.
  • Cabut akses: buka myaccount.google.com/permissions, pilih SiGaji, lalu hapus akses.
  • Hapus data di Drive: pada halaman akses yang sama, pilih SiGaji lalu hapus data aplikasi yang tersimpan di Drive.
  • Hapus data di perangkat: hapus data situs ini lewat pengaturan browser.

Karena kami tidak menyimpan data Anda di server, penghapusan di langkah-langkah di atas menghapus data tersebut sepenuhnya.

Keamanan

Koneksi memakai HTTPS. Token disimpan terenkripsi dan tidak dapat dibaca oleh skrip di halaman. Tidak ada sistem yang sepenuhnya bebas risiko; jaga akun Google dan perangkat Anda, dan buat cadangan lewat tombol Unduh.

Anak-anak

Layanan ini ditujukan untuk pelaku usaha dan tidak ditujukan untuk anak-anak.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini dengan tanggal pembaruan baru.
